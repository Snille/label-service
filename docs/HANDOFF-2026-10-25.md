## What 0.5.0 changes

Phase 0 of Label Studio (the design report lives in the label-studio repository, `docs/forstudie.md`):

- One SVG drawing per label: real font metrics, text as outlines, `rsvg-convert` makes the PDF for CUPS and PNG previews. The PostScript generator is gone.
- Template format v1 with saved, versioned templates (draft, published, archived) and client roles (designer, drafter).
- `box`, `location` and `lines` are built-in templates in the new format; their API and `layout.lines` are unchanged for Storage System Base.
- Settings hold several printers (5XL, 550, 550 Turbo, 450, 4XL); the CUPS image has both DYMO drivers.

## Verified without printing

- Offline CUPS raster through `lw5xl.ppd`: page sizes match 0.4.1 exactly for all five formats; inked areas match within 0.7 mm, also for rotated labels. Two narrow box labels wrap the description onto more rows (real metrics are wider than the old estimate); they still fit.
- `lw450` queue: accepts PDF, raster conversion gives the expected page.
- API image: saved template, preview with PNG, Unicode glyphs (→, °).
